# 知天下 v0.3.0

稳定代码版本，固定配套 Provider A v0.5.0。继承 v0.3.0-rc.1 的持久任务、
断线续接、240 秒公网订阅轮换、历史恢复与安全错误页；保留原 RC tag。

发布前补齐按帧合并流式渲染、减少计时器重复更新、静态 gzip 与 ETag 校验，
并修复干净 Node 源码模式的固定 Markdown 依赖资源路径。界面设计不变，
问答事件、原文、安全过滤和 JSON/SSE 合同不变。性能范围见
[评测记录](../FRONTEND_PERFORMANCE_20261010.md)，不把资源预算等同真实用户指标。

## 新安装

从本仓库固定 v0.3.0 tag／完整源码归档进入，先取得私有源码及 GHCR 镜像权限，
阅读 README 和 docs/AGENT_DEPLOYMENT.md。推荐 onboard Docker 双服务入口，
自动选择配套 Provider；Node 高级路线仍保留。两边 Release 附件固定提交和
ARM64/AMD64 镜像摘要，不分别选两个“最新版”，不使用浮动 main。
账号扫码、手机确认和知识库授权仍需人工，不附送 Air 账号。

## 证据与限制

发布门槛为完整合成回归、构建、资源预算、配套 Docker CI、双架构原生启动、
私有镜像可见性及最终 manifest。确切结果以 Release 附件和本次报告为准。
本次不发送真实 IMA 问题；既往 Air 真实首问／追问不是新镜像复验。
Windows 真机、远程 SSH 扫码、真机软键盘、新账号完整扫码及 Linux 长期运行
尚未验收。Mac 浏览器尺寸模拟和 CI Linux 启动不能替代这些项目。

Air 在线演示仍可能偶发 503，依赖 Air、网络及隧道；稳定版本标记不表示公网
可用性已经通过或具备 24 小时生产承诺。代码发布与运行服务割接分别管理。

## 升级与回退

先更新／确认 Provider 持久任务能力，准备固定产物，停止准入并排空网站与
Provider 队列，再备份私有配置和当前数据，单写入者切换。保留 Cookie 密钥、
访客归属、待发回执、账号与全部卷，不重新 init，不执行 down -v。

回退仅选择兼容任务协议的代码，保留新增历史及日志；不回退为旧直连路径，
不重新提交结果不确定的任务。GitHub Release 不自动更新 Air 4317/4318、
Docker 4417、机器人或账号池；Vercel Git 部署只更新代理。
