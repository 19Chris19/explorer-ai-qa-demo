# v0.5.1 首页与发送体验

网站首页调整视觉对齐、推荐问题和输入框层次。推荐问题填入与发送动作使用连续动画，发送立即提交；失败保留草稿，结果不确定时继续核对原任务，不自动重复提问。桌面、移动尺寸、触屏和减少动态效果使用合成测试覆盖。

交流群面板目前为不可扫码的示意，真实资料待配置。麦克风仍为不录音的视觉预览；联网开关的请求语义保持不变。

本版配套 Provider v0.7.0，不改变 Provider、账号或机器人协议。升级前核对实际 Release 和镜像清单；已有安装先关闭提交并证明排空，保留私有配置与迁移兼容代码，备份后更新网站和转发层。回滚保留最新会话与任务数据，不以旧备份覆盖历史。

合成测试和静态资源检查不代表 iOS Safari、Android Chrome 真机手感或线上真实问答验收。新版本号与源码提交也不能单独证明镜像已发布或现有安装已更新。
