# v0.5.0 配套弹性调度与网站受理保护

固定配套：Provider A v0.7.0。账号调度只在 Provider 执行，网站读取自己的实际
应用额度，继续由现有 BFF、网关和 Vercel 转发，浏览器不接触账号或服务密钥。

命名应用的普通与内部凭据须由服务端返回相同 applicationId；配额损坏或暂停
新受理时拒绝新增任务，旧任务仍可查询。legacy 凭据兼容但不宣称身份隔离通过。
提交频率、公开待发数、单会话待发数和连接超时改为有界配置，默认值不扩大。

同会话串行、未知结果仅查询原请求、SSE 游标续接与历史恢复保持兼容。多入口
共享 Provider 的额度，不能把网站、MCP 和 CLI 的容量相加。真实五路 Provider/BFF
链路及更高额度须单独验收，不能把官方网页观察或模拟上游结果作为稳定吞吐承诺。

发布工作流兼容已经公开的源码仓库，保留版本合并检查、不可变镜像标签和私有
容器包可见性检查；不改注册表包权限。已有安装需排空、备份、先更新 Provider、
再更新 BFF；Cookie 签名、登录态、密钥、历史与 Air 机器人不迁移或重建。
