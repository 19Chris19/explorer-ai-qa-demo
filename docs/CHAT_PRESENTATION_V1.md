# 问答引用、追问与表格工具

本次升级接入 Provider A 的可选 `presentation=chat_v1` 读取视图。先更新兼容 Provider 后端，再更新本网站；保持现有会话归属、Cookie 签名、任务记录、迁移补丁和账号登录态。部署时先做私有备份并保留回滚补丁，不用 main 覆盖正在运行的迁移目录。

正文中的联网引用使用上游引用键精确关联。显示编号与引用键可以不同，来源乱序、同一网页被多次引用、摘要迟到更新都不会按数组顺序猜配。悬浮或键盘聚焦角标可查看标题、域名与上游实际摘要；只有一个明确网页目标时，鼠标点击或键盘激活角标直接在新标签页打开原网页，保留问答页。触屏/触笔首次点按打开底部来源面板，只展示该角标对应网页；重复点角标不跳转，点击整张来源卡片访问原网页，支持小叉、遮罩、Escape 和下拉把手关闭。若同一引用对应多个不同网页，则在卡片中明确选择，不按数组顺序挑选。摘要缺失时不补写。完整网页图文由新标签页按原网站显示；停留 300ms 后可按需读取受限缓存的网页分享封面；抓取默认关闭，不截图或执行网页脚本。

知识库引用只有静态角标。界面不提供库名、文件标题、内容预览、上游标识或知识库跳转。旧历史缺少映射时保留原文或静态引用，不重新问答补数据。代码、公式和普通数字不作引用处理。

“回答过程”只展示已有证据支持的资料检索、联网搜索与回答生成。当前回答对应的最多三条推荐问题与首页题库并存；点击只填入输入框，允许编辑后手动发送。有草稿、任务处理中或正在切换会话时不能覆盖输入。

表格提供独立复制和 CSV 下载：剪贴板同时提供 HTML 与 TSV，CSV 使用 UTF-8 BOM，处理中文、引号、逗号、换行和公式前缀。生成中禁止导出；有效的部分回答表格明确标注。原 Markdown 整段复制和代码块独立复制保留。

数据贯通 Provider 任务快照/SSE/历史、BFF、浏览器重放及迁移归档。BFF 再次投影展示数据，过滤不应展示的来源和过程字段，并逐帧保留原事件 ID、心跳和恢复游标。推荐问题在本地任务完成前保存，不额外调用模型；恢复不重复提交任务。

新 JS/CSS 已加入本机服务、受保护网关和 Vercel 代理的静态资源允许列表，构建产物与 Docker 构建包含后端投影模块。本变更不会自动修改 Vercel 配置或启动/部署服务。

已提供合成测试与本地浏览器验收。真实问答、生产发布、真实手机及 Excel/Numbers/文档粘贴仍需分别验收；Air 机器人接入保持现状。
