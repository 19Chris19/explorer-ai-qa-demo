# 网页封面与手机来源面板

桌面悬浮/聚焦先显示引用标题、域名和上游摘要，停留 300ms 后按需读取封面。
单一网页角标保留原生新标签页行为，多网页引用由用户在卡片内选择。
触屏首次点按打开底部模态面板，只列该角标对应网页；重复点角标不跳转，
整张来源卡片链接到原网页。小叉、遮罩、Escape 和下拉顶部把手可关闭。
关闭后恢复焦点和阅读位置。知识库引用保持绿色静态角标，无预览或跳转。

封面是原网页声明的 Open Graph/Twitter 分享图片，可能与网页实际布局不同。
取不到图片、超时、后端较旧或繁忙时保留文字。绝不启动浏览器截图、执行页面
脚本或回退到截图服务。引用的标题、摘要、网址不由封面元数据替换。

两端从首个封面请求开始共享 2 秒显示预算，覆盖元数据、图片传输和图片解码。
桌面 300ms 停留确认不计入这 2 秒；手机明确点按后开始请求。到期取消请求，
仅保留文字及链接，不提示问答错误、不自动重试，也不接纳迟到的图片。
滚动面板、重复点按和迟到的引用元数据不会重置预算或重试已尝试来源。
用户明确关闭后重新打开，才是一次新的查看。已经及时显示的图片可以继续保留。

BFF 的 `/api/qa/source-preview` 与 `/api/qa/source-preview/image` 只允许 GET，
使用签名 Cookie 对应的归属身份，转发到 Provider 的受服务凭证保护接口。
请求只带会话/任务/引用键/sourceId，不接受任意 URL。Provider 从已有引用
映射解析目标，并在缓存命中和图片读取前验证归属。旧迁移归档没有可靠任务
关联时继续使用文字卡片。`chat_v1` sourceId 按网址计算，不写入原始历史。

网关及 Vercel 明确放行这两个路径，允许 JPEG、PNG、WebP，阻断 SVG/HTML，
并限制图片 512KiB、元数据 4KiB。图片通过现有认证读取并以临时 blob 显示，
不让访客浏览器直接请求第三方图片；HTTP 响应保持 private no-store。
构建产物包含 source-preview.mjs，CSP 只增加所需的 blob 图片权限。

Provider 统一限流/缓存，两端不分别抓取。同一时刻 1 个抓取任务、0 排队；
每滚动分钟最多 6 个新网页/12 次 HTTP（含重定向及图片）；总时限 3 秒；
HTML 解压后 256KiB，缓存 7 天/失败 1 小时，最多 128MiB/2,000 条。
问答排队、容量耗尽或维护时不开始新抓取。缓存位于私有运行目录，可单独禁用，
不重启问答、不改变登录态、Cookie 签名、任务或 Air 机器人路由。

部署顺序：兼容 Provider 后端（封面开关关闭）→两端前端及网关→验收后开启
受限获取。保留私有备份和回滚补丁，不用 main 覆盖迁移代码。
本次 PR 不自动部署。合成性能、浏览器触屏模拟不等于真实 IMA、外网或手机真机
验收；真实问答、生产发布、iOS Safari/Android Chrome 真机测试分别确认。
