# 语音输入离线实验

本分支只提供独立、可合成测试的录音状态、PCM 编码、腾讯实时识别协议与会话签名模块；尚未接入首页、网站路由、Vercel、网关或 CSP。默认无法创建真实会话，也不申请麦克风权限或连接云服务。首页视觉须先经人工审阅。

## 体验与数据

用户主动点击后才允许请求麦克风；识别时可在输入框附近展示逐步更新的转写预览。停止后只有收到识别服务的最终完成消息才把文字插入用户当前草稿，不覆盖选区、不自动发送。错误保留已收到的预览供用户手动处理。取消、拒绝权限、断线和超时都关闭本地媒体资源，不自动重试。

音频和识别文字只在本次会话中处理；业务代码不写日志、历史或缓存。真正接入时，应在请求麦克风之前告知用户录音将交给腾讯云转写；服务商的数据处理仍须以实际条款为准，不能承诺对方不保留数据。

## 合成合同与尚未打通的部分

`voice-tencent-signature.mjs` 按腾讯官方实时识别签名格式生成短时地址，仅在合成测试中使用虚拟凭据，不连接服务。浏览器模块限制目的地为固定腾讯 ASR 域名、PCM 单声道 16kHz、约 200ms 一帧，并区分中间结果和最终结果。

`voice-admission.mjs` 只限制**单个服务进程生成会话的频率和本地租约**。浏览器直连后，签名地址可能被复制、重放或继续占用云侧资源；地址有效期和本地租约都不能证明云侧连接已经终止，也不能保证单次使用或支出上限。因此当前不新增公开签名路由，也不放宽 `connect-src 'self'`。

启用前必须解决并实测签名重放、云侧并发和费用保护，确认腾讯引擎的热词支持、凭据和计费条件，并验证 Vercel 转发、网关白名单、同源保护、CSP、iOS Safari、Android Chrome、嵌入页面麦克风权限和断线清理。若不能限制风险，保持关闭并评估受控中转方案。

本分支没有创建云账户、申请密钥、上传真实语音或支付费用，也没有验证任何实际识别准确率。人工真实语音测试、云服务开通及上线需要各自确认。
