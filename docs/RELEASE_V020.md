# v0.2.0 主站外壳与同域接入

## 更新

- 使用主站真实 Logo、导航图标、字体、桌面侧栏尺寸和页头语言；保留
  AI 问答、交流群占位和更多，不复制作品筛选或搜索功能。
- 保留 Hero、单条候选、胶囊输入栏、流式 GFM、安全过滤、来源、复制、
  划词复制、停止与排队能力。语音仍只是动画，不录音。
- 同域 `/qa-app/` 模块适配：父页面管理导航、主题和语言，内部外壳隐藏；
  校验消息来源、版本、路径和 Cookie/浏览器存储命名空间。
- demo/test/production 使用独立配置样例和私有状态，不虚构 Test 域名。
- 本地 Node 和 Docker 使用同一个固定版本；私有镜像含 AMD64/ARM64，
  镜像摘要以通过验收的 Release 附件为准。

## 升级与回退

新安装按 `VERSIONED_RELEASES.md` 初始化。已有安装不得重新初始化、重生成
凭证或覆盖账号/会话。先备份、确认网站与 Provider 队列空闲，再只更新网站
代码/镜像和网关白名单；Provider A、Bot 不随之重启。

保留上一兼容代码指向和镜像，失败时停止新写入进程，切回旧代码并保留当前
数据。不要用旧会话或账号快照覆盖新增数据。主站接入前阅读
`MAIN_SITE_ADAPTER.md`，避免第二套侧栏和顶栏。

## 已知边界与部署者验收

4318 外观已获用户通过。窄屏默认隐藏侧栏，目前没有展开按钮；这是本版本
接受的边界。手机使用紧凑导航，不宣称像素级复刻；横屏短高度允许滚动。
交流群资产未配置，不宣称可以入群。

本次自动化使用合成问答，无新增真实 IMA 复验。部署者应显式进行一问一
追问，核对流式正文、表格、来源、唯一完成、同会话衔接与刷新历史，记录
脱敏结论即可。真实主站环境、真机软键盘和 Linux 长期运行仍需单独验收。
Air 在线预览依赖 Air 在线，不等于生产 24 小时服务。
